# Dock采集器

一个本地运行、规则驱动的可视化采集工具。两个目标独立配置、独立运行、独立导出。

## 启动

macOS 可以直接双击项目根目录中的 `启动Dock采集器.command`。它会启动服务并自动打开控制台；在终端窗口按 `Control+C` 可以停止。

Windows 可以双击项目根目录中的 `启动Dock采集器.bat`。首次启动会建立独立的 Windows 虚拟环境，并自动安装依赖和程序内置 Chromium；后续启动会直接打开控制台。首次安装需要联网，并要求系统已安装 Python 3。

也可以使用命令行：

```bash
python3 run.py
```

然后访问 <http://127.0.0.1:3780>。

首次启动不包含任何预置目标或网站数据。新增目标后，预登录会打开程序内置的 Chromium 窗口；登录状态只保存在本机对应目标的 `浏览器数据` 目录。检测到验证码后，采集器先用 ddddocr 本地自动识别（支持字符验证码、算术题自动计算、旋转字符增强和极验滑块）；自动处理失败或无法识别的类型时暂停该目标，手动完成验证后自动恢复。

浏览器使用项目 `.browsers` 目录中的 Playwright Chromium，不依赖电脑上安装的 Chrome。字段提取页提供“可视化规则拾取器”：打开本地样例或目标网页，点击要保存的内容即可生成 CSS 选择器并加入规则。

## 核心规则

- 列表行必须包含配置的文字（默认“昨天”），否则不打开详情。
- 每个版块可设置固定代理，留空时继承目标代理。
- 可配置列表/详情间隔、最大页数、最大详情数、最长运行时间和字段命中结束条件。
- SQLite 用于去重和断点数据；CSV 按目标独立导出。
- 代理用于授权网络环境的固定出口，不提供用于规避网站限制的自动轮换。

## 文件

- `collector.db`：本机配置、采集结果和事件日志（不会提交到 Git）。
- `<目标目录>/浏览器数据`：各目标的本机登录状态（不会提交到 Git）。
- `目标*/目录.txt`：首次创建规则时导入的版块入口。
