配置说明

每项设置的作用范围、触发时机和常见用法。修改后请点击“保存设置”，运行中的任务通常在下次启动时读取新配置。

任务控制

开始任务 / 继续任务

没有断点时从第一个数据列表开始；存在断点时按钮自动显示“继续任务”，从保存的数据列表、页码或瀑布流批次继续。恢复页面时仍会使用详情网址去重，不会重复保存已有结果。

重新开始

清除运行断点并从第一个数据列表重新开始，但不会清空采集结果；已经保存过的详情网址会在打开详情前直接跳过。

断点保存

进入数据列表页、翻页或进入新的瀑布流批次时自动保存。暂停保留当前浏览器；停止、验证码中断或程序异常会保留断点。全部数据列表正常完成后自动清除断点。

重命名目标

修改当前目标在标题和左侧列表中的显示名称。目标 ID、目录、规则、账号、代理和历史结果关联保持不变，运行中也可修改。

开始、暂停、继续与停止

“开始任务”创建新任务；运行时可点击“暂停任务”，暂停后同一按钮变为“继续任务”；“停止任务”会立即关闭该任务的 Chromium 浏览器进程并结束采集，但保留已有结果和登录状态。暂停与停止都不会清空结果。

清空采集结果

“采集结果”页面中的“清空”只删除当前目标的全部采集结果和去重记录，不会自动开始任务。删除的结果无法恢复。

实时结果

停留在“采集结果”页面时每 1.5 秒检查一次新增记录；有变化才更新表格，并保留当前分页位置。

数据列表

启用

控制本次任务是否处理该数据列表。关闭只会跳过，不会删除规则、账号或历史结果。

作用范围：单个数据列表

列表名称

用于控制台状态、结果版块列和账号管理中的显示名称，不参与网页定位。

数据列表页地址

该数据列表开始采集的入口地址。多个数据列表按照当前排序依次执行。

作用范围：单个数据列表

独立代理

填写后覆盖目标代理；留空则继承目标代理。不同独立代理不能复用同一个浏览器进程。

列表筛选

列表项容器 CSS 选择器

定义“一条待判断记录”的外层元素。例如 Discuz 常见规则为 tbody[id^="normalthread_"]。必含文字和详情链接都在该容器内部查找。

详情链接 CSS 选择器

在每个列表项内部定位详情入口。如果选中的是链接元素，程序读取其 href；字段提取中也可通过属性方式保存链接。

列表时间 CSS 选择器

在每个列表项内部定位真正用于筛选和导出的发布时间。页面一行中存在发布时间、最后回复时间等多个时间时，只有该元素参与判断。

时间必须包含的文本（多个值）

支持填写一个或多个包含值，使用中文逗号、英文逗号或换行分隔，例如 昨天，小时前，分钟前。“任意命中（OR）”表示时间元素包含任意一个值即可采集；“全部命中（AND）”表示同一时间元素必须同时包含全部值。例如填写 昨天, 11: 并选择 AND，可匹配“昨天 11:51”。匹配方式为包含，不要求整个时间文本完全相等。

列表项过滤规则

在过滤规则区域选择数据列表与浏览器账号，点击“打开浏览器 · 新增过滤规则”，再点击当前列表项内部的标题、作者或分类等具体元素。每条规则可填写多个判断值，使用中文逗号、英文逗号或换行分隔，并选择“任意命中（OR）”或“全部命中（AND）”。命中后只跳过当前这一条数据，不打开详情，不会结束当前数据列表或整个任务。已有规则可重新打开浏览器选择判断元素。

翻页方式

普通分页选择“下一页按钮”并配置选择器；没有翻页按钮的瀑布流选择“滚动到底加载”，程序每轮滚动到页面底部并等待“列表间隔”，列表项数量不再增加时结束当前数据列表。

列表规则自动识别与手动修正

自动识别确认后直接保存四个定位规则。手动修正会载入当前已保存规则，只需点击对应的修正按钮并重选不准确的项目，再保存全部规则；两种方式均可选择统一账号、独立账号或游客状态。

识别按钮

“后台识别并保存规则”不会显示浏览器窗口；所有会启动独立 Chromium 的按钮统一使用“打开浏览器 · 动作”格式，例如“打开浏览器 · 修正列表规则”。

下一页 CSS 选择器

当前列表页处理完成后用于定位下一页或加载更多链接。找不到该元素时结束当前数据列表。

字段提取

字段名称

导出 CSV 的列名。同名字段会自动增加序号，建议使用稳定且易理解的名称。

提取方式

css 使用 CSS 选择器；label_next 查找标签后的相邻元素；discuz_showhide 读取 Discuz 隐藏内容；breadcrumb 读取面包屑；body_after_fields 清理结构化字段后保留正文。

正文（排除字段）

适用于正文与地址、价格、联系方式等结构化内容位于同一个帖子容器的页面。拾取器会只高亮结构化字段之后的正文，规则使用通用帖子选择器，不绑定某一个帖子编号。

选择器或标签文字

根据提取方式填写 CSS 选择器或页面上的字段标签。可通过可视化规则拾取器生成。

属性

留空时提取元素文字；填写 href、src 等属性时保存属性值。需要采集链接时使用 href。

字段包含即不采集

每条元素提取规则都可填写一个或多个逗号分隔的排除词。字段提取完成后，只要任意字段命中自己的排除词，整条详情都会跳过且不写入结果。

内容页网址与浏览器账号

字段拾取器不再选择数据列表页。请直接填写需要提取字段的完整内容页网址，再选择统一账号、游客状态或某个数据列表的独立账号后打开。网址必须以 http:// 或 https:// 开头。

访问频率

列表间隔（秒）

当前列表页处理结束后，打开下一列表页前的等待时间。它不作用于同一页内的每条详情。常用范围为 10～30 秒。

作用范围：每次翻页

详情间隔（秒）

打开下一条详情前的等待时间。一页有 10 条匹配内容时会执行 10 次该等待。限制严格的网站建议适当提高。

作用范围：每条详情

超时（秒）

单次页面导航允许等待的最长时间。页面提前完成就立即继续，并非每页固定等待到超时值。普通网络可设 30～45 秒，代理环境可设 45～90 秒。

作用范围：单次页面加载

最大重试

单次页面加载失败后允许再次尝试的次数。例如设置 2，含首次请求在内最多尝试 3 次。

当前状态：配置已保留，自动重试链路仍在完善

错误退避（秒）

加载失败后再次尝试前的等待时间，用于避免网络、代理或网站异常时连续请求。普通错误可设 30～60 秒，疑似访问限制可设 300 秒以上。

当前状态：配置已保留，自动退避链路仍在完善

读取上限

最大列表页

普通分页时表示每个数据列表最多读取的页数；瀑布流模式下表示最多执行的加载批次数。当前数据列表达到上限后继续下一条数据列表。

作用范围：单个数据列表

最大详情数

当前任务所有数据列表累计允许打开的详情总数，不是单个数据列表上限。例如设置20，列表1打开12条后，其他数据列表合计只剩8条额度。

作用范围：整个目标任务

最长运行（分钟）

从目标任务启动开始计算的总运行时间，达到后停止任务，包括等待间隔和页面加载时间。

作用范围：整个目标任务

连续空页停止

连续多少个列表页没有找到符合筛选条件的内容后结束当前数据列表。找到匹配内容时计数清零。设置1表示第一张无匹配页面就结束。

作用范围：单个数据列表

连续验证码未通过上限

自动打码失败并回退人工时不会立即停止。人工提交后验证码仍存在且验证码内容刷新，才记为一次未通过；自动或人工验证成功后连续次数立即清零。达到上限后停止任务。状态栏“验证码”仅表示本次任务检测到验证码的总次数，不作为停止依据。

作用范围：连续未通过次数

连续错误上限

设计用于连续页面加载或采集异常的停止阈值；成功加载后应清零。它与验证码次数分开统计。

当前状态：配置已保留，连续错误链路仍在完善

可视化停止条件

判断对象

可选择已提取字段、页面元素或页面全文。字段直接从现有提取规则中选择；页面元素可填写 CSS，也可使用已登录账号打开浏览器点击选择。

判断方式与多个值

支持包含、等于、不包含、元素出现、元素消失和内容为空。判断值可以填写多个，使用中文逗号、英文逗号或换行分隔。“任意命中（OR）”表示任意值成立即命中；“全部命中（AND）”表示全部值都成立才命中。出现、消失和内容为空不需要填写判断值。

停止范围

“停止当前数据列表”会继续执行下一条数据列表；“停止整个目标”会正常结束本次目标任务。多条启用条件中任意一条命中即执行。

可视化选择页面元素

填写完整页面网址并选择统一账号、独立账号或游客状态，然后点击“打开浏览器 · 选择停止元素”。在浏览器中点击目标元素后，CSS 选择器自动写回新条件；已有元素条件可重新打开浏览器选择。

账号与代理

所有数据列表使用统一账号

所有数据列表共用一个浏览器登录状态。账号目录和代理一致时复用同一个 Chromium 连续采集。

每个数据列表使用独立账号

每条数据列表拥有独立浏览器配置、Cookie 和缓存，适合数据列表必须使用不同账号的情况。

混合模式

默认继承统一账号，个别数据列表可切换为独立账号。账号和代理分别继承，因此同一账号也可以搭配不同数据列表代理。

直连、固定代理与代理 API

直连使用本机网络；固定代理始终使用配置地址；代理 API 在启动数据列表前请求代理地址。API 可设置请求方式、认证头、POST 正文、JSON 路径和重试次数。

运行模式

可视运行

始终显示独立浏览器，适合首次调试规则和观察采集动作。

后台静默

使用临时无窗口浏览器并导入已保存 Cookie，不直接读取持久化账号目录中的 Chromium Safe Storage，可减少 macOS 钥匙串授权弹窗。验证码需要人工处理时无法显示页面，应停止后切换模式。

自动切换

正常采集时最小化；检测到验证码时恢复窗口，处理完成后再次最小化。

验证码

代理和打码栏目

主界面的“代理和打码”统一管理目标级直连、固定代理、代理 API，以及验证码自动识别、目标专用补充文案和检测选择器。

自动打码

启用后使用 ddddocr 处理字符、算术、旋转字符及支持的滑块验证码；无法识别时回退人工处理。

自动尝试次数

一次验证码事件允许自动识别和提交的次数。每次失败可刷新验证码，全部失败后暂停等待人工处理。

详情结构保护

验证码处理后，程序必须再次检测到目标的正常详情字段结构才允许解析和保存；如果仍是验证页，可视模式会暂停等待人工完成，静默模式会停止，防止生成整条空数据。

检测文字

系统内置中英文验证码、人机验证、滑块、访问频繁和异常流量等常见文案；这里填写的是目标专用的补充文字，用逗号分隔。文字不会单独决定结果，还会与验证组件及正常字段结构共同评分。

检测选择器

用于识别验证码图片、输入框或验证面板，每行一个 CSS 选择器。系统还会结合正常采集结构、URL 和内容变化判断是否真正通过。

页面指纹与异常评分

程序会记录本次任务中最近 20 个正常详情页的正文长度和字段结构命中数。新页面与正常页差异明显时会等待后复核；确认结构异常则跳过而不保存，发现验证或登录信号则暂停处理。

推荐顺序：先低频可视运行验证规则 → 完成账号登录与验证码测试 → 检查导出字段 → 再逐步提高读取上限或切换后台模式
