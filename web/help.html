配置说明

每项设置的作用范围、触发时机和常见用法。修改后请点击“保存设置”，运行中的任务通常在下次启动时读取新配置。

页面来源

启用

控制本次任务是否处理该来源。关闭只会跳过，不会删除规则、账号或历史结果。

作用范围：单个来源

来源名称

用于控制台状态、结果版块列和账号管理中的显示名称，不参与网页定位。

列表页地址

该来源开始采集的入口地址。多个来源按照当前排序依次执行。

作用范围：单个来源

独立代理

填写后覆盖目标代理；留空则继承目标代理。不同独立代理不能复用同一个浏览器进程。

列表筛选

列表项容器 CSS 选择器

定义“一条待判断记录”的外层元素。例如 Discuz 常见规则为 tbody[id^="normalthread_"]。必含文字和详情链接都在该容器内部查找。

详情链接 CSS 选择器

在每个列表项内部定位详情入口。如果选中的是链接元素，程序读取其 href；字段提取中也可通过属性方式保存链接。

必须包含的列表文本

列表项包含该文字才打开详情。例如填写“昨天”，只判断列表项，不会因为详情正文出现“昨天”而采集。

下一页 CSS 选择器

当前列表页处理完成后用于定位下一页或加载更多链接。找不到该元素时结束当前来源。

字段提取

字段名称

导出 CSV 的列名。同名字段会自动增加序号，建议使用稳定且易理解的名称。

提取方式

css 使用 CSS 选择器；label_next 查找标签后的相邻元素；discuz_showhide 读取 Discuz 隐藏内容；breadcrumb 读取面包屑；body_after_fields 清理结构化字段后保留正文。

选择器或标签文字

根据提取方式填写 CSS 选择器或页面上的字段标签。可通过可视化规则拾取器生成。

属性

留空时提取元素文字；填写 href、src 等属性时保存属性值。需要采集链接时使用 href。

拾取器页面来源与浏览器账号

页面下拉框显示已添加的“页面来源规则”，也可以临时输入完整网页地址。选择页面来源规则时，浏览器账号会自动切换到该来源实际使用的统一账号或独立账号。账号也可手动改为统一账号、游客状态或其他独立账号。

访问频率

列表间隔（秒）

当前列表页处理结束后，打开下一列表页前的等待时间。它不作用于同一页内的每条详情。常用范围为 10～30 秒。

作用范围：每次翻页

详情间隔（秒）

打开下一条详情前的等待时间。一页有 10 条匹配内容时会执行 10 次该等待。限制严格的网站建议适当提高。

作用范围：每条详情

超时（秒）

单次页面导航允许等待的最长时间。页面提前完成就立即继续，并非每页固定等待到超时值。普通网络可设 30～45 秒，代理环境可设 45～90 秒。

作用范围：单次页面加载

最大重试

单次页面加载失败后允许再次尝试的次数。例如设置 2，含首次请求在内最多尝试 3 次。

当前状态：配置已保留，自动重试链路仍在完善

错误退避（秒）

加载失败后再次尝试前的等待时间，用于避免网络、代理或网站异常时连续请求。普通错误可设 30～60 秒，疑似访问限制可设 300 秒以上。

当前状态：配置已保留，自动退避链路仍在完善

读取上限

最大列表页

每个页面来源最多读取的列表页数。来源1达到上限后继续来源2，并重新计算页数上限。

作用范围：单个来源

最大详情数

当前任务所有来源累计允许打开的详情总数，不是单个来源上限。例如设置20，来源1打开12条后，其他来源合计只剩8条额度。

作用范围：整个目标任务

最长运行（分钟）

从目标任务启动开始计算的总运行时间，达到后停止任务，包括等待间隔和页面加载时间。

作用范围：整个目标任务

连续空页停止

连续多少个列表页没有找到符合筛选条件的内容后结束当前来源。找到匹配内容时计数清零。设置1表示第一张无匹配页面就结束。

作用范围：单个来源

验证码上限

任务中检测到验证码的累计次数。无论自动或人工是否处理成功都会计数，达到上限后停止任务。

作用范围：整个目标任务

连续错误上限

设计用于连续页面加载或采集异常的停止阈值；成功加载后应清零。它与验证码次数分开统计。

当前状态：配置已保留，连续错误链路仍在完善

内容结束条件

命中字段名

选择需要检查的提取字段名称，例如“正文”或“标题”。应与字段提取规则中的名称完全一致。

字段包含即停止

指定字段的提取结果包含该文字时结束当前来源。需要同时填写“命中字段名”才会生效。

详情包含文本

详情页面原始 HTML 包含任意指定文本时结束当前来源。多个条件使用逗号分隔。

账号与代理

所有来源使用统一账号

所有来源共用一个浏览器登录状态。账号目录和代理一致时复用同一个 Chromium 连续采集。

每个来源使用独立账号

每条来源拥有独立浏览器配置、Cookie 和缓存，适合来源必须使用不同账号的情况。

混合模式

默认继承统一账号，个别来源可切换为独立账号。账号和代理分别继承，因此同一账号也可以搭配不同来源代理。

直连、固定代理与代理 API

直连使用本机网络；固定代理始终使用配置地址；代理 API 在启动来源前请求代理地址。API 可设置请求方式、认证头、POST 正文、JSON 路径和重试次数。

运行模式

可视运行

始终显示独立浏览器，适合首次调试规则和观察采集动作。

后台静默

无窗口运行并减少桌面干扰。验证码需要人工处理时无法显示页面，应停止后切换模式。

自动切换

正常采集时最小化；检测到验证码时恢复窗口，处理完成后再次最小化。

验证码

自动打码

启用后使用 ddddocr 处理字符、算术、旋转字符及支持的滑块验证码；无法识别时回退人工处理。

自动尝试次数

一次验证码事件允许自动识别和提交的次数。每次失败可刷新验证码，全部失败后暂停等待人工处理。

检测文字

页面包含任意指定文字时视为可能出现验证码。不同网站文案不一致时，可添加多个文字并用逗号分隔。

检测选择器

用于识别验证码图片、输入框或验证面板，每行一个 CSS 选择器。系统还会结合正常采集结构、URL 和内容变化判断是否真正通过。

推荐顺序：先低频可视运行验证规则 → 完成账号登录与验证码测试 → 检查导出字段 → 再逐步提高读取上限或切换后台模式
